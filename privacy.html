Daily Hub

Privacy policy

Effective October 25, 2026

Daily Hub is a personal planning tool that runs only on its owner's computer and is used only by its developer, Colin Mitchell, with his own accounts. This policy explains what it does with data from Google accounts.

Data it accesses

  • Gmail (gmail.readonly): message headers (sender, recipients, subject, date), short previews and labels of recent mail.
  • Google Calendar (calendar.readonly): event titles, times, locations and attendees.
  • Inbox cleanup (gmail.modify, a separate permission granted only if the owner turns cleanup on): used only to apply labels, archive, or move to Trash messages the owner has reviewed and approved. It is never used to send, draft, or permanently delete email.

How it's used

Only to show the owner his own day: a calendar view, a suggested task list, reminders about mail that needs a reply, and suggested inbox cleanup batches that do nothing until he approves them. Data is not used for advertising, is not sold, and is not used to build profiles of anyone.

Where it's stored

In a database file on the owner's own computer, along with the sign-in tokens Google issues. There is no Daily Hub server or cloud database. Local backups, kept on the same computer, leave out stored email and sign-in tokens.

Who it's shared with

To write the daily plan and cleanup suggestions, short excerpts (sender, subject, date and preview) are sent to Anthropic's Claude API for processing. Anthropic does not use API data to train its models by default. No other party receives Google user data, and no person other than the owner reads it.

Limited Use

Daily Hub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting Daily Hub's data folder on the owner's computer removes all stored data.

Contact

Questions about this policy: open an issue on this site's GitHub page.
